Class Coding Projects

Lab #2 - Coding & Posting a Web Page - The Basics

This lab introduces the foundations of building a web page with HTML and publishing it online. It is a starting point for practicing clear structure, meaningful content, and the basic building blocks of the web.

Lab #3 - Tables, Forms, Tabbed Browsing, and Screen Reading

This lab explores ways to organize information in tables, collect input with forms, and use browser tabs. It also introduces screen-reader testing to help check that page content and controls make sense when read aloud.

Lab #4 - Accessible CSS Layout

This lab focuses on using CSS to arrange page content while keeping it readable and usable. Flexible layouts, responsive design, good contrast, and keyboard access all contribute to a more accessible experience.
